# 五线谱快快乐 — 制谱规则

## SVG 坐标系

viewBox: `0 0 560 310`，原点 (0,0) 在左上角。

- x 轴：从左到右，0 → 560
- y 轴：从上到下，0 → 310

## 五线谱线条

五条线从下到上（y 从大到小）：

| 线 | y |
|---|---|
| 第 1 线（最下） | 220 |
| 第 2 线 | 180 |
| 第 3 线 | 140 |
| 第 4 线 | 100 |
| 第 5 线（最上） | 60 |

线间距固定 40px。

## 辅助标记

- 左侧竖线（barline）：x = 108，从 y=60 到 y=220
- 音符中心 x：330
- 半音步高：20px（HS），step 0 = 最下面一条线（y=220）

## 谱号位置

### 高音谱号 (𝄞)

```
x: 105
y: 242        （文字基线，即字符底部）
fontSize: 309
字体: 'Times New Roman', 'Georgia', serif
颜色: #4B5563
```

左边缘贴齐竖线 (x≈108)，上下沿与五线谱最上/最下线相切 (y=60~220)。

### 低音谱号 (𝄢)

```
x: 108
y: 200        （文字基线）
fontSize: 206
字体: 'Times New Roman', 'Georgia', serif
颜色: #4B5563
```

位置规则同高音谱号，左贴竖线，上下沿切齐五线谱范围。

## step → y 换算

```js
noteY(step) = 220 - step * 20
```

- Treble: step 0 = E4 (y=220, 最下线)
- Bass: step 0 = G2 (y=220, 最下线)
- step 向上每 +1 = y 向上 20px
